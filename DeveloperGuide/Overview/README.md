# FSDH Overview

## Current Artifacts

### Portal

- Web interface to FSDH workspaces

### [RBAC Function (Python)](../Security/WorkspaceUsersRBAC.md)

- Assign RBAC in storage account
- Assign RBAC in databricks  
- Communicates with portal via secure service bus

### [Infrastructure Functions](./Artifacts/InfraFunctions.md)

- Manages common background processes required for workflows
- Invitations, Emails, HealthChecks, ProjectUsage
- Communicates with portal via secure service bus
- Manages AV Notifications and workflows

### [Resource Provisioner](./Artifacts/ResourceProvisioner.md) 

- Generates terraform for Devops pipelines with workspace resources
- Communicates with portal via secure service bus

### Devops TF pipeline

- Applies terraform changes generated by resource provisioner
- Listens to pull requests in Azure Devops Git repository
